# Generic Meds Australia

A responsive frontend website recreated as part of my internship project.

## Project Overview

This project is a frontend implementation of the Generic Meds Australia website. The focus was on creating a clean, responsive layout that works across desktop, tablet, and mobile devices.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome

## Features

- Responsive design
- Product search interface
- Shopping cart counter
- Responsive navigation
- Product sections
- Customer reviews section
- Contact and assistance sections
- Mobile, tablet and desktop compatibility
